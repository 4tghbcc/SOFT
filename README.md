## 🎯 О проекте

**Web Project Manager** — лёгкое автономное веб-приложение для управления проектами и задачами, разработанное для ООО «Софт-Эксперты». Приложение не требует серверной инфраструктуры, работает полностью в браузере и хранит данные в `localStorage`.

### ✨ Ключевые возможности

- ✅ Создание, переключение и удаление проектов
- ✅ Добавление задач с приоритетами (высокий / средний / низкий)
- ✅ Отметка задач как выполненных
- ✅ Автоматическая сортировка задач по статусу и приоритету
- ✅ Статистика по проектам и задачам в реальном времени
- ✅ Экспорт/импорт данных в формате JSON (резервное копирование)
- ✅ Автосохранение состояния между сеансами
- ✅ Адаптивный дизайн для мобильных устройств
- ✅ Полная автономность — работает без интернета
